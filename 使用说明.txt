张家港市中等专业学校 · 门户网站（毕业设计 Demo）
=====================================================

【怎么打开】
  双击 index.html 即可在浏览器中打开（推荐 Chrome / Edge）。
  不需要安装环境、不需要联网。
  改了内容看不到变化时，按 Ctrl + F5 强制刷新。

【前台能点哪儿】
  顶部导航 9 个栏目：学校首页 / 学校概况 / 新闻中心 / 教学管理 / 专业设置 /
                    招生就业 / 德育之窗 / 党建园地 / 智慧校园
  · 首页右上角搜索框：输入关键词回车（或点"搜索"），进入站内搜索结果页，
    标题 / 摘要里的关键词会高亮；侧栏还有热门搜索与按栏目浏览
  · 首页右侧"校园公告"：每条都能点，直接进公告正文
  · 左侧栏目导航（内页）：每一条都能点。带数字的是该栏目文章数量，
    点了就是按分类筛选；学校概况 / 教学管理 / 党建园地 / 招生就业 的左侧导航
    点了会跳到本页对应的段落，位置已自动避开吸顶导航。
  · 新闻中心：分类胶囊 + 左侧栏目筛选，点标题进详情页（文末有上一篇 / 下一篇）
    列表按每页 8 条分页，底部"上一页 / 1 / 2 / 下一页"都能点，当前页高亮
  · 学校概况：学校简介、校训与三风、办学特色、校园环境相册、学校荣誉、
              发展记事时间线、组织机构、校徽校歌
  · 教学管理：教学运行、专业建设、课程教材、实训基地、师资队伍、教学质量监控
  · 招生就业：四种办学层次、报名四步流程、招生信息表、升学与就业
  · 专业设置：5 个系部标签切换，共 18 个专业
  · 德育之窗：五心育人专题（红心 / 仁心 / 恒心 / 匠心 / 创心）
  · 党建园地：组织建设、三会一课、主题党日时间线、思政育人
  · 右上角"字号 A- A+"：无障碍字号放大，会被记住
  · 右上角官方微信二维码：鼠标移上去会放大
  · 右下角"AI 问答"：问报名、专业、地址、学费等，自动作答（演示用本地知识库）

【后台演示账号】
  入口：顶部导航"智慧校园"或右上角"后台登录"
  账号 admin　密码 123456　验证码随便填

  后台可真实增删改，数据存在浏览器本地：
  1) 工作台：文章总数 / 待审核 / 累计浏览 / 未读留言四个指标都是实时计算的；
     右侧「待办与快捷」把待审核、草稿、未读留言、缺封面、启用轮播五项直接点进对应列表
  2) 文章管理：新建 / 编辑 / 发布 / 下架 / 置顶 / 删除 / 按栏目和关键词筛选
     表格左侧可勾选（含全选），选中后出现「批量发布 / 批量下架 / 批量转待审 / 批量删除」
  3) 封面图：编辑页右侧可"点击或拖拽上传"，自动压缩到宽 1280px；
     上传后文章列表出现缩略图，前台新闻列表与详情页同步显示这张图
     编辑页右下角实时显示正文字数，Ctrl + S（Mac 为 ⌘+S）可直接保存
  4) 图片素材库：批量上传图片、放大预览、查看被引用次数、删除
  5) 轮播与公告：上传首页大图、启用 / 停用、上移 / 下移排序；
     排在最前面且处于启用状态的那张，就是前台首页的大图（改完回前台刷新即可看到）
  6) 栏目管理 / 留言管理 / 用户与角色 / 操作日志
  7) 系统设置：「数据备份」可导出整站数据为 json 文件，也可导入恢复
  8) 发布后回到前台刷新，首页与新闻列表立即出现该文章（前后台共用一份数据）
  9) 后台顶栏（面包屑 / 搜索 / 消息）已隐藏，左侧菜单即可切换页面
