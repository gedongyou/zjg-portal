# 张家港市中等专业学校 · 门户网站（含后台管理）

> 信息工程系 2022 级毕业设计作品 · 主题方向「'五心'苏式工匠」—「为学校设计数字形象」
> 选题：学校门户网站设计与实现（含后台管理）

纯静态站点，原生 HTML + CSS + JavaScript 实现，无需构建、无需后端，可直接部署到 GitHub Pages。

## 一、项目结构


## 二、功能一览

**前台**

- 首页：校名头部（真校徽 + 搜索 + 官方微信二维码）、9 项主导航、快捷通道、大图 Banner、校园公告、数据带（360 亩 / 28 专业 / 6200 学生 / 419 教师 / 78 金）、新闻双栏、校园服务、系部导航、五心育人专题、页脚
- 栏目页：学校概况（简介 / 校训三风 / 办学特色 / 校园环境相册 / 荣誉 / 发展记事 / 组织机构 / 校徽校歌）、新闻中心、教学管理、专业设置（5 系部 18 专业）、招生就业、德育之窗（五心）、党建园地
- 新闻中心：10 个分类筛选、每页 8 条分页、详情页配图与上一篇 / 下一篇
- 站内搜索：标题 / 摘要 / 栏目命中，关键词高亮，热门搜索与按栏目浏览
- 左侧栏目导航：可点击，带文章计数；内页导航点击跳转到对应段落（自动避开吸顶栏）
- 无障碍字号调节（A− / 默认 / A+），记忆在本地
- 智能问答浮窗：报名、专业、地址、学费等常见问题，本地知识库加权匹配
- 响应式：≥1280 / ≤1240 / ≤1080 / ≤720 四档

**后台**

- 工作台：文章总数、待审核、累计浏览、未读留言实时统计；待办与快捷入口
- 文章管理：新建 / 编辑 / 发布 / 下架 / 置顶 / 删除，按栏目与关键词筛选，勾选后批量操作
- 封面上传：点击或拖拽，自动压缩到宽 1280px；列表缩略图、前台列表与详情同步显示
- 轮播与公告：上传首页大图、启用停用、上移下移排序，排在最前的启用图即前台首页大图
- 图片素材库：批量上传、放大预览、被引用次数、删除
- 栏目管理、留言管理、用户与角色、操作日志、系统设置（数据备份导出 / 导入）
- 编辑页显示正文字数，支持 Ctrl / ⌘ + S 保存

## 三、本地运行

方式一：双击 `index.html`（Chrome / Edge）。

方式二：起一个静态服务器（推荐，行为与线上一致）：

```bash
python -m http.server 8080
# 打开 http://localhost:8080/index.html
```

数据保存在浏览器 localStorage，换浏览器或清除站点数据会回到初始示例数据。

## 四、部署到 GitHub Pages

```bash
git init
git add .
git commit -m "张家港市中等专业学校门户网站（毕业设计）"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

然后在仓库页面 **Settings → Pages**：

- Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`
- 保存后等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 仓库需为 **Public**（私有仓库的 Pages 需要 GitHub Pro）。
> 若访问 404，确认根目录存在 `index.html` 与 `.nojekyll`，并在 Actions 里查看 pages build 是否成功。
